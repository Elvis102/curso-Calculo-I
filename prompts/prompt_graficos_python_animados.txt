Usar cuando la curva se describe con UNA sola fórmula (polinomio, seno, gaussiana…)

# f(a) = f(c) = 1 → slope = 0 → b exactamente en el máximo
f(x) = -(x - a)**2 * (x - c) / K + 1
df(x) = -(x - a) * (3x - (a + 2c)) / K
# Altura del máximo: yb = (c-a)³ / (4K) + 1

## TIPO B — Curva por tramos (piecewise)

Usar cuando la curva necesita mostrar tipos distintos de puntos críticos
(máximos, mínimos, inflexión, esquina, discontinuidad) que no pueden modelarse
con una sola fórmula. Cada tramo se precomputa como array antes de `plot_XX`.

**Patrón de curva con 4 tramos:**
```
Tramo 1: Seno suave  →  mín / máx / inflexión
Tramo 2: Cúbica      →  punto de inflexión claro (x³ trasladada)
Tramo 3: Segmento lineal  →  subida hacia esquina (corner)
Tramo 4: Descenso + gap + segmento derecho  →  discontinuidad
```

**Cómo conectar tramos suavemente (C¹):**
```python
# Para conectar f_seno con f_cubica en x_union con continuidad C¹:
# 1. Calcula la pendiente de la cúbica en x_union: dy_union = df_cubica(x_union)
# 2. Calcula la fase del seno que iguale esa pendiente:
_phase = np.arccos(np.clip(dy_union / (B * W), -1, 1))
_phi   = _phase - W * x_union
# 3. Calcula el offset vertical para igualar el valor:
_A    = y_union - B * np.sin(W * x_union + _phi)
# 4. Función seno resultante:
def f_seno(x): return _A + B * np.sin(W * x + _phi)
```

**Discontinuidad — círculo abierto + círculo cerrado:**
```python

## ERRORES COMUNES Y CÓMO EVITARLOS

| Problema | Causa | Solución |
|---|---|---|
| La gráfica no aparece en el panel | `plt.show()` solo, sin llamar la función | Reemplazar por `plot_XX(...)` |
| El segundo tramo crea un máximo no deseado | `_xs4` demasiado largo (llega al pico gaussiano) | Limitar: `np.linspace(x_r, x_r + 0.6, 50)` |
| Dos marcadores se ven idénticos | Mismo color Y misma forma (`'s'`) | Cambiar color O forma (ej: `'^'` triángulo) |
| Los cambios no aparecen tras editar | Quarto sirve figuras cacheadas | Borrar `_files/figure-revealjs/*` y re-renderizar |
| Variable de otro slide pisa la función | Nombres genéricos (`f`, `plot`, `a`, `slope`) | Prefijo único por slide en TODO: `f_XX`, `plot_XX`, `a_XX` |
| Arccos da fase errónea en conexión C¹ | Ambigüedad de signo en `arccos` | Verificar que la derivada calculada coincide con la pendiente esperada |

## TIPO D — Animación continua con FuncAnimation (GIF auto-reproducible)

Usar cuando la visualización requiere movimiento continuo (punto recorriendo una curva,
proyecciones dinámicas, hélice 3D, etc.) en lugar de estados discretos por clic.

**Principio:** `FuncAnimation` genera fotogramas; se exporta como GIF embebido en base64
dentro del HTML. El GIF se auto-reproduce en loop sin botones ni interacción del usuario.

### Estructura obligatoria del chunk

```python
```{python}
#| echo: false
from matplotlib.animation import FuncAnimation
from IPython.display import HTML
import base64, tempfile, os

# 1. Crear figura y artistas estáticos (una sola vez)
fig, ax = plt.subplots(figsize=(10, 6))
# ... configurar ejes, curvas de fondo, paneles, etiquetas fijas ...

# 2. Crear artistas animados (listas vacías — se rellenan en update)
dot,  = ax.plot([], [], 'o', color='crimson', ms=9, zorder=10)
line, = ax.plot([], [], 'r--', lw=1.5)
# (tantos artistas como elementos se muevan)

# 3. Función update(frame) — SOLO modifica artistas, no recrea figura
def update(frame):
    ti = t[frame]
    dot.set_data_3d([ti], [f(ti)], [g(ti)])   # 3D
    # dot.set_data([ti], [f(ti)])              # 2D
    line.set_data([...], [...])
    return dot, line   # devolver TODOS los artistas modificados

# 4. Crear animación
anim = FuncAnimation(fig, update, frames=N, interval=40, repeat=True, blit=False)

# 5. Exportar GIF a archivo temporal y embeber en base64
_tmp = tempfile.mktemp(suffix='.gif')
anim.save(_tmp, writer='pillow', fps=25, dpi=72)
plt.close()
with open(_tmp, 'rb') as _f:
    _b64 = base64.b64encode(_f.read()).decode()
os.remove(_tmp)
HTML(f'<img src="data:image/gif;base64,{_b64}" style="max-width:100%; max-height:75vh;" />')
```
```

### Errores frecuentes y soluciones

| Error | Causa | Solución |
|---|---|---|
| `TypeError: argument should be str, not BytesIO` | `anim.save(BytesIO(), ...)` — Pillow no acepta buffer | Usar `tempfile.mktemp(suffix='.gif')` y leer después |
| La animación no se mueve (jshtml) | `to_jshtml(default_mode='loop')` configura el modo pero no auto-inicia | Usar el flujo GIF base64 en lugar de jshtml |
| Botones de control visibles (jshtml) | La clase CSS puede diferir entre versiones de matplotlib | El GIF no tiene botones por diseño |
| GIF demasiado pesado (>20 MB) | N grande + dpi alto | Reducir `N` o `dpi` (ej: `dpi=60`, `N=90`) |
| Fotogramas en blanco o negros | `plt.close()` antes de `anim.save()` | Llamar `anim.save()` ANTES de `plt.close()` |
| Artista no actualiza en 3D | `set_data([x], [y])` en lugar de `set_data_3d` | Usar `artist.set_data_3d([x], [y], [z])` para ejes 3D |
| `blit=True` causa artefactos en 3D | blitting no es compatible con ejes 3D | Usar siempre `blit=False` en figuras 3D |

### Parámetros clave

```python
N        = 180          # fotogramas (180 = 1 ciclo completo a 25 fps → ~7 s)
interval = 40           # ms entre fotogramas en la animación JS (irrelevante para GIF)
fps      = 25           # fotogramas por segundo en el GIF exportado
dpi      = 72           # resolución: 72 limpio, 60 más ligero, 96 más nítido
```
